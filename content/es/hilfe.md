# Ayuda

## ¿Qué hace TalkCreator?

TalkCreator te ayuda a preparar guías estructuradas para entrevistas, pódcast, debates o conversaciones en clase. Organizas la conversación en tres fases (introducción, parte principal y conclusión), añades una lista de preparación y fuentes, y al final imprimes una guía clara.

## Inicio rápido

1. **Crear el proyecto:** Introduce el título del proyecto y el grupo objetivo o los participantes en el editor. La primera vez se carga un proyecto de ejemplo que puedes sustituir directamente.
2. **Editar elementos:** Añade preguntas o tareas a la introducción, la parte principal y la conclusión. Cada elemento puede incluir notas, una duración estimada y la marca «Opcional / Reserva». Reordena los elementos arrastrando el control o usando los botones de flecha, también entre fases.
3. **Usar el resultado:** La vista previa en directo muestra tu guía. Usa **Imprimir / PDF** para obtener la guía final o **Exportar (MD)** para crear un archivo Markdown.

## Guardar y abrir proyectos

Tu proyecto actual se guarda automáticamente en el navegador y estará disponible en tu próxima visita en el mismo dispositivo y navegador.

Para crear una copia de seguridad o cambiar de dispositivo, usa **Guardar** para descargar el proyecto como archivo `.json`. Usa **Cargar** para abrir uno de estos archivos. El almacenamiento local automático no sustituye a una copia de seguridad: si borras los datos del navegador, el proyecto desaparece, mientras que los archivos exportados se conservan.

## Eliminar datos

- **Restablecer proyecto** (el icono situado en la parte superior del editor) elimina el proyecto actual y carga un proyecto de ejemplo vacío.
- Todos los datos almacenados localmente se eliminan cuando borras los datos de este sitio en tu navegador.

## Dispositivos y archivos compatibles

- **Navegadores:** Versiones actuales de Firefox, Chrome, Edge y Safari en equipos de escritorio y dispositivos móviles. En pantallas estrechas, usa el selector superior para cambiar entre el editor y la vista previa.
- **Archivos:** Archivos de proyecto `.json` (máximo 512 KB), exportación Markdown (`.md`) o impresión/PDF mediante el diálogo de impresión del navegador.
- **Sin conexión:** Después de la primera visita, la aplicación también funciona sin conexión a Internet.
