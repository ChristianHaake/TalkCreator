# Help

## What does TalkCreator do?

TalkCreator helps you plan structured conversation guides for interviews, podcasts, debates, or classroom discussions. You organize the conversation into three phases (introduction, main section, and conclusion), add a preparation checklist and sources, and print a clear guide when you are finished.

## Quick start

1. **Set up the project:** Enter the project title and target group or participants in the editor. A sample project is loaded on first use and can be overwritten directly.
2. **Edit items:** Add questions or tasks to the introduction, main section, and conclusion. Each item can include notes, an estimated duration, and an “Optional / Backup” marker. Reorder items by dragging the handle or using the arrow buttons, including between phases.
3. **Use the result:** The live preview shows your guide. Select **Print / PDF** for the finished guide or **Export (MD)** for a Markdown file.

## Saving and opening projects

Your current project is saved automatically in your browser and will be available on your next visit on the same device and in the same browser.

For backups or moving to another device, select **Save** to download the project as a `.json` file. Select **Load** to open one of these files. Automatic local storage is not a backup: clearing your browser data removes the project, while exported files remain available.

## Deleting data

- **Reset project** (the icon at the top of the editor) deletes the current project and loads an empty sample project.
- All locally stored data is removed when you delete this site's data in your browser.

## Supported devices and files

- **Browsers:** Current versions of Firefox, Chrome, Edge, and Safari on desktop and mobile. On narrow screens, use the switch at the top to move between the editor and preview.
- **Files:** Project files use `.json` (maximum 512 KB). You can export Markdown (`.md`) or print/save a PDF through the browser's print dialog.
- **Offline:** After the first visit, the app also works without an internet connection.
