# About TalkCreator

## Purpose

**TalkCreator** is an open-source project for education. It helps students, teachers, and media creators prepare conversations: podcast or report interviews, debates, classroom discussions, and project presentations. A clearly structured guide with time planning, a checklist, and sources makes the preparation tangible.

## How it works

TalkCreator runs entirely in your browser. There is no sign-in, no user account, and no application server communication. Your project is stored locally in your browser. You can export it as a file (**Save**), import it again (**Load**), or print it as a conversation guide.
