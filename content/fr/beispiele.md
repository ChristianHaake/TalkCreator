# Exemples

TalkCreator propose des modèles de départ locaux pour les podcasts, les interviews, les débats et les échanges en classe. Ils contiennent des exemples génériques et sont traités dans le navigateur.

Choisis un modèle dans l’éditeur. Il remplace le projet actuel après confirmation. Exporte ton travail avant si tu souhaites le conserver.
